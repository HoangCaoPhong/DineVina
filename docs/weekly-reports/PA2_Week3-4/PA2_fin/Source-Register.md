## Quality decisions
**Performed by:** Hoàng Cao Phong | **Reviewed by:** Võ Mỹ Ngọc (assigned; review record not supplied) | **Edited by:** Hoàng Cao Phong

- The assignment requires Scrum. RUP is used only as a Vision document structure; the Plan remains five Scrum sprints.
- A table request is distinct from a confirmed reservation. An event inquiry has a separate proposal path.
- Proposed targets and architecture are labelled as plans. No completed workflow, meeting or test is claimed solely because a draft describes it.
- Supporting copies in this package standardize the initial reservation state name as `AWAITING_CONFIRMATION` and use uniform report wording. The source branches remain unchanged; implementation should reconcile identifiers against the approved API contract before coding.
- The supplied materials do not establish individual training completion for all five members, complete AI-use declarations or actual PA2 ceremony minutes. Their status is stated explicitly in the package rather than invented.
